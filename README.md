# Warehouse Optimizer

A Power BI dashboard for inventory risk detection, warehouse transfer recommendations, and cost optimization.

## Features

- Executive overview of revenue, savings, at-risk products, and cost reduction
- Stockout risk monitoring using safety-stock and lead-time indicators
- Naïve versus optimized cost comparison
- Warehouse transfer recommendations between locations

## Dashboard Pages

1. Executive Overview
2. Risk Monitor
3. Cost Impact
4. Transfers

## Tool Used

- Microsoft Power BI
